# 自衛官 給料表ナビ

階級と号俸から俸給月額を確認し、昇任・賞与・手当を含む生涯年収を試算するブラウザ向けアプリです。

公開先: https://fushimin1892.github.io/jsdf-lifetime-simulator/

## ファイル構成

- `index.html` — 画面の構造
- `css/` — 画面と印刷用のスタイル
- `data/` — 俸給表、昇任表、計算に使う規則
- `js/` — 試算、俸給の検索、画面操作、印刷
- `icons/` — アイコン画像
- `AI用/` — 修正ガイドと検証用スクリプト

ビルドは不要です。ローカルで確認する場合は、このディレクトリを静的サーバーで配信して開きます。
