# 自衛官 給料表ナビ　AI向け改修ガイド

このファイルは、今後このサイトを AI（Claude など）に改修させるときに、そのまま渡すための指示書です。
「## AIへの指示（このまま貼り付け）」の部分をコピーして、やりたいことを書き足して渡してください。

最終更新：2026-10-30（法令と照合した日。`window.RULES.checkedOn` と同じ日付にする）

## AIへの指示（このまま貼り付け）

```
あなたは「自衛官 給料表ナビ」（自衛隊生涯シミュレーター/index.html）の改修担当です。
次のルールを必ず守ってください。

1. 返答・説明・報告はすべて日本語で書く。
2. 編集するのは 自衛隊生涯シミュレーター/index.html だけ。
   「書き換え不可.html」は絶対に開いて書き換えない・消さない。
3. サイトは1ファイル（index.html）のまま。外部ファイルや外部ライブラリを増やさない。
4. 法令の数値（俸給表・手当の割合や額・賞与の月数・定年・退職手当・若年定年退職者給付金・
   共済掛金・税金）は、index.html 内の「window.RULES」ブロックと、
   「window.PAY_TABLE」「window.PROMOTION_TABLE」ブロックだけに書く。
   計算プログラムの中に数値を直接書き込まない。
5. 数値を変えるときは、必ず一次資料（e-Gov 法令検索、人事院、国税庁、防衛省共済組合など）の
   原文で確認し、どの条文・資料のどの値かを報告する。推測で数値を入れない。
   「人事院勧告」はまだ法律ではない。法改正が成立したかどうかを確かめてから反映し、
   未成立なら説明文にその旨を書く。
6. 数値を変えたら、画面の説明文（「説明・計算の前提」ページに集まる文章、選択肢の文言）に
   同じ数値が書かれていないか検索して、一緒に直す（下の「文章の中の数値」を参照）。
7. 改修の前と後に「検証用スクリプト.js」をブラウザで実行し、結果を比べる。
   計算に関係しない改修なら hash が改修前と同じであること。
   数値を変えた改修なら、変わった項目が改正の内容どおりであることを確認して報告する。
8. スマホ幅（375px）で横にはみ出さないこと、コンソールにエラーが出ないことを確認する。
9. 最後に、変えた値・根拠・確認したこと・確認できなかったことを日本語で報告する。

やりたいこと：
（ここに書く）
```

### 「上限以下なら値」の表の読み方

`tax.basicByYear` や `retirement.selfReduction` などは `[上限, 値]` を上限の小さい順に並べた表です。
計算では「値が上限以下になる最初の行」を使います。最後の行の上限は `Infinity`（それ以上ずっと）です。

## 計算で簡略化していること（改修で精度を上げるときの候補）

- 標準報酬は `kyosai.stdTable`（共済組合法第40条の等級表）で、資格取得時決定・定時決定（4〜6月平均→9月）・随時改定（3か月平均が2等級以上→4か月目）を入れている。
  簡略化：報酬が変わった月はすべて「固定的給与の変動」とみなす。随時改定は短期・年金のどちらかの表で2等級以上ずれたら両方を改定。
  退職等年金の上限は厚生年金と同じ（`pensionCaps`）としている。営内の食事など現物給与は報酬に含めていない。
- 所得税・住民税は暦年で計算。入隊前の収入は0。所得税は月ごとの給与額に比例して割り振る（表示用）。
  住民税は翌年6月〜翌々年5月の12回、1〜4月退職は5月までを一括徴収、それ以外の退職後の分は `afterResident` として生涯の手取りから引く。
- 若年定年退職者給付金：60歳以後の分（3回目・4回目）は所得による調整を入れていない。
  2回目以降の退職所得控除は、前の退職手当等（退職手当＋それまでの給付金）と勤続期間が重なる年数を引き、下限80万円（施行令第70条第1項第2号イ・第2項）。
  前の退職手当等の合計が控除額に満たないときは、前の勤続期間を縮めて計算する。
  扶養手当は退職時の額が翌年も続くとしている。年の途中からの再就職は12か月分に直して入力してもらう。
- 入隊区分（`entryType`）：一般曹候補生（今までどおり）、任期制（任期ごとに任期満了金。満了退職か3曹昇任かを選ぶ。3曹へ昇任した場合は満了金を受けた任期を退職手当の勤続期間から除く。
  任期の途中で昇任したときの施行令第25条の特例は、一般の退職手当の額の方が大きいので一般の額で計算）、一般幹部候補生（大卒・修士・院卒。候補生の間は教育期間）。
  任期制の任用一時金・自衛官候補生の制度は令和8年10月時点の法律にないので入れていない。休職・育児休業による日数の減算（第28条第2項）は入れていない。
- 結果欄の「条件を比べる」：run() の最後に要約（latestSummary）を作り、保存したA（savedSummary）と並べる。計算には関係しない。
  「年齢ごとの内訳」は初めは閉じた details、「退職時・退職後の給付」は開いた details。印刷ではどちらも開き、比べていないときは比較の欄を出さない。
- 退職後：国民年金保険料（「退職後〜60歳の年金」で自分で納めるを選んだ場合）。「免除を受ける（退職による特例免除）」なら保険料0で、免除した月を老齢基礎年金に2分の1で数える（国民年金法第27条第8号、`afterRetire.exemptRatio`）。免除の可否（配偶者・世帯主の所得）は判定しないと健康保険料（入力した年額×年数、任意継続は2年まで）を生涯の手取りから引く。
  65歳からの公的年金は参考表示（老齢基礎年金の満額＋報酬比例。退職等年金給付・加給年金・再評価なし）で、生涯の手取りには含めない。
- 共済掛金の報酬に営内の食事（現物給与）は含めない（共済組合法施行令第5条第3項第7号：一般職の報酬に相当する給与だけ。一般職に食事の現物給与はない）。
- 特定管理職員は1佐以上で特別調整額一種・二種の人だけ（施行令第12条の5の除外の書き方から、2佐・3佐は対象外と読める）。
- 地域手当の異動保障（第11条の7第1項）：支給終了が定年より前で、6か月を超えて在勤した地域手当を「異動」とみなし、
  1年目100％・2年目80％・3年目60％の割合を保障（新しい勤務地の割合が高い月はそちら）。
  簡略化：3年以内の再異動（人事院の定め）は、重なる保障のうち高い割合を使う。異動前の割合は異動前月の年度の割合。
- 「条件から計算」（扶養・住居・通勤・単身赴任・寒冷地手当）は、入力した条件の月額が支給期間中ずっと同じとしている。
  寒冷地手当は11〜3月の5か月分を12か月にならして毎月加える。営内居住・世帯主でない乗組員は上限の半額で計算。
  通勤手当で電車と車を併用する場合は規則9-24第8条の4どおり（車2km以上は両方、2km未満は高い方。上限15万円）。駐車場の手当（第12条第5項）は入れていない。
  扶養手当の父母等の額は、将補（2）欄・1佐（1）欄で0円、1佐（2）欄で3,500円（施行令第8条の7・第8条の8、`calcRates.fuyouParentByCol`）。
- 俸給表の「昇給の見通し」は、同じ階級のまま年4号俸（将補・1佐（1）（2）欄は極めて良好の年2号俸、将は昇給なし）で、最高号俸で止める。
- 地域手当は年度ごとに割合を切り替える。
  - 令和10年4月以後：人事院規則9-49 別表第一（本則）＝ `allowances.regionalAreas`
  - 令和7年4月〜令和10年3月：人事院規則9-49-57 附則別表第一（経過措置）＝ `allowances.regionalTransition.byFy`（2025＝令和7年度、2026＝令和8年度）。表に載っていない地域はこの期間0％。
  - 令和9年度（2027）の表はまだ公布されていないので、令和8年度の表を使っている。**毎年2月ごろ**に人事院規則9-49-57の改正（新旧対照表）が出たら `byFy` に年度を足す。
  - 原文の入手先：人事院の改正通知ページの「新旧改め文（PDF）」。JILPT の法令ページ（例：2026年2月13日の 9-49-57-2）に同じ表が文字で載っていて取り出しやすいが、まれに表の一部の文字が欠けるので PDF と突き合わせる。
  - 東京都武蔵村山市は令和8年度の改正後の表に載っていない（令和7年度は7％）。原文どおり令和8年度は0％にしている。
  - 空港の区域（成田16％・中部12％・関西12％、規則9-49第4条）は経過措置の対象外として、全期間同じ割合。
- 特殊作戦隊員手当：施行令第12条第5項にある 26・21・16・10％ の区分は、選択肢に入れていない（対応する訓令の区分を未確認）。
- 乗組手当：施行令第12条第2項の「その他の乗組員」（階級の最低号俸×43・26.4・16.5％）は選択肢に入れていない。
- 配置手当の上限（施行令第12条第10項：将の俸給の額との差額まで）は入れていない。
- 昇任時の号俸は施行令第6条の6のとおり、別表第一ロの対応表を1階級ずつ順に当てはめる（直近上位ではない）。
  例：3曹28号俸（311,300円）→2曹20→1曹16→曹長16→准尉16→3尉20号俸（325,300円）。
  防衛大臣が別に定める特例（第6条の8・第6条の10）があれば実際と違う場合がある。
- 扶養手当・住居手当・通勤手当・単身赴任手当・寒冷地手当などは、利用者が金額を入力する方式（自動計算していない）。
- 同じ日に複数の特殊勤務手当を受けた場合の「高いほうだけ」の決まり（施行令 別表第五の備考）は入れていない。
