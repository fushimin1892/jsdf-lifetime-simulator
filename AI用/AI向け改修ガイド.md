## AIへの指示（このまま貼り付け）

```
あなたは「自衛官 給料表ナビ」（自衛隊生涯シミュレーター/index.html）の改修担当です。
次のルールを必ず守ってください。

1. 返答・説明・報告はすべて日本語で書く。
2. サイトは index.html（画面の骨組み）・css フォルダ（デザイン）・data フォルダ（俸給表と法令の数値）・
   js フォルダ（計算と動き）に分かれている。どこに何があるかは下の「ファイルの構成」を見る。
3. 外部ライブラリを増やさない。新しいファイルを足すときは、index.html の読み込み順に気をつける。
   css / js / data のファイルを直したら、index.html の「?v=日付」を全部新しい値に変える（同じ日に2回目なら 日付-2 など）
   （古いファイルがブラウザに残って、新旧が混ざるのを防ぐため）。
4. 法令の数値（俸給表・手当の割合や額・賞与の月数・定年・退職手当・若年定年退職者給付金・
   共済掛金・税金）は、assets/data/rules.js（window.RULES）と、
   assets/data/pay-table.js（window.PAY_TABLE）・assets/data/promotion-table.js（window.PROMOTION_TABLE）だけに書く。
   js フォルダの計算プログラムの中に数値を直接書き込まない。
5. 数値を変えるときは、必ず一次資料（e-Gov 法令検索、人事院、国税庁、防衛省共済組合など）の
   原文で確認し、どの条文・資料のどの値かを報告する。推測で数値を入れない。
   「人事院勧告」はまだ法律ではない。法改正が成立したかどうかを確かめてから反映し、
   未成立なら説明文にその旨を書く。
6. 数値を変えたら、画面の説明文（「説明・計算の前提」ページに集まる文章、選択肢の文言）に
   同じ数値が書かれていないか検索して、一緒に直す（下の「文章の中の数値」を参照）。
7. `node test/check.js` が NG 0 であること。改修の前と後に「検証用スクリプト.js」をブラウザで実行し、結果を比べる。
   法令改正の反映は「AI用/改正対応の手順書.md」の順に進め、出典（assets/data/sources.js）も更新する。
   計算に関係しない改修なら hash が改修前と同じであること。
   数値を変えた改修なら、変わった項目が改正の内容どおりであることを確認して報告する。
8. スマホ幅（375px）で横にはみ出さないこと、コンソールにエラーが出ないことを確認する。
9. 最後に、変えた値・根拠・確認したこと・確認できなかったことを日本語で報告する。

やりたいこと：
（ここに書く）
```

### クラス名の決まり（BEM ＋ 目的の接頭辞）

クラス名は `ブロック__要素--変化`（BEM）で書き、先頭に目的を表す接頭辞を付けます。新しく足すときも同じ決まりにしてください。

| 接頭辞 | 意味 | 例 |
|---|---|---|
| `l-` | ページの骨組み（レイアウト）。1ページに1つずつ | `l-header`・`l-main`・`l-footer`・`l-bg`（背景） |
| `c-` | 部品（コンポーネント）。どこに置いても同じ見た目 | `c-hero`・`c-lookup`・`c-simulator`・`c-allowance-item`・`c-btn--primary` |
| `u-` | 1つの役目だけの補助 | `u-visually-hidden`（読み上げだけ）・`u-screen-only`（印刷しない） |
| `is-` | JS が付け外しする状態 | `is-error`・`is-show`・`is-dim`・`is-highlight`・`is-printing`・`is-scrolled` |

- 要素は `__`、変化は `--` でつなぐ（例：`c-allowance-item__name`、`c-legend__swatch--net`、`l-bg__mark--1`）。
- JS がクラス名で探す所（`querySelector(".c-…")`・`classList`・`className`・HTML を組み立てる文字列の `class="…"`）も同じ名前を使う。名前を変えるときは HTML・CSS・JS・テスト（`test/`・`AI用/検証用スクリプト.js`）を一緒に直す。
- 2026-11-24 に、それまでの名前（`sim-…`・`a-…`・`allowance-…` など）を一括で置き換えた。古い名前と新しい名前の対応は git の履歴（「クラス名を BEM に統一する」のコミット）で確かめられる。

### HTML の骨組み

`l-header`（ページ上部）→ `c-hero`（俸給を調べる）→ `c-ticker`（流れる帯）→ `main.l-main`（シミュレーターの dialog と俸給表）→ `l-footer`。
まとまりは `section`、その見出しの帯は `header`、出典・計算の前提は `footer` にしている。CSS の `header` の指定はタグ名ではなく `.l-header` に付けている（ほかの header に効かないように）。

### 俸給表の列番号（PAY_TABLE・RULES で共通）

`0 将 / 1 将補(1) / 2 将補(2) / 3 1佐(1) / 4 1佐(2) / 5 1佐(3) / 6 2佐 / 7 3佐 / 8 1尉 / 9 2尉 / 10 3尉 / 11 准尉 / 12 曹長 / 13 1曹 / 14 2曹 / 15 3曹 / 16 士長 / 17 1士 / 18 2士`

- `PAY_TABLE[号俸−1][列番号]` が俸給月額（その号俸がなければ `null`）。
- `PROMOTION_TABLE[昇任前の号俸−1][列番号−2]` が昇任後の号俸。

### 「上限以下なら値」の表の読み方

`tax.basicByYear` や `retirement.selfReduction` などは `[上限, 値]` を上限の小さい順に並べた表です。
計算では「値が上限以下になる最初の行」を使います。最後の行の上限は `Infinity`（それ以上ずっと）です。

## 計算で簡略化していること（改修で精度を上げるときの候補）

- 標準報酬は `kyosai.stdTable`（共済組合法第40条の等級表）で、資格取得時決定・定時決定（4〜6月平均→9月）・随時改定（3か月平均が2等級以上→4か月目）を入れている。
  簡略化：報酬が変わった月はすべて「固定的給与の変動」とみなす。随時改定は短期・年金のどちらかの表で2等級以上ずれたら両方を改定。
  退職等年金の上限は厚生年金と同じ（`pensionCaps`）としている。営内の食事など現物給与は報酬に含めていない。
- 所得税・住民税は暦年で計算。入隊前の収入は0。所得税は月ごとの給与額に比例して割り振る（表示用）。
  住民税は翌年6月〜翌々年5月の12回、1〜4月退職は5月までを一括徴収、それ以外の退職後の分は `afterResident` として生涯の手取りから引く。
- 若年定年退職者給付金（2026-11-24 に作り直し。`simulator.js` の `youngPension()`）：退職した月で制度を選ぶ（`youngPension.periods`：令和8年3月以前・令和8年度・令和9年度は2回払い＋施行令第22条の率、`newSystem`：令和10年4月以後は3回払い・率なし）。60歳以後の分は61歳の年の所得で調整（給与年額相当額は100分の70、勤勉手当の率は省令附則第5項の表。表にない年は最後の年の率を仮定）。定年60歳以上（将・将補）は附則第13項（55〜70％）。所得金額は「給与所得＋事業所得」を給与収入に直した額（`ypIncome`）。支給月は省令第1条（1回目は4月か10月、2回目は翌々年8月）。60歳以後の1回目の月と、令和10年4月以後の3回目の月は省令が未定・未確認のため仮定。令和10年4月以後の「給与年額調整額」は政令が未公布で、画面の `ypAssume`（上限＝加算調整上限額／加算なし）で選ぶ。加算調整上限額の手当は月ごとの `kasan`（俸給の特別調整額・対象の手当・勤勉手当）を退職日から12か月ずつ区切った最高の年。
- 税：給付金の1回目は退職所得（退職手当と同じ年なら合わせて控除、別の年なら重なる勤続年数を引く）、2回目以降と一時に受け取る分は一時所得（50万円控除後の2分の1を再就職の給与・事業所得に加えて増える税。社会保険料控除は入れない）。退職所得控除の勤続年数は1年未満を切り上げ（所得税法施行令第69条第2項。退職手当の勤続期間とは別の `nt`）。給与所得は別表第五（`salaryIncome`。660万円未満は4,000円単位）、所得金額調整控除は特定扶養親族か扶養手当の子がいる年。通勤手当は非課税限度額（`commute.nontaxCar`）までを非課税。
- 以前の版：若年定年退職者給付金の60歳以後の分は所得による調整を入れていなかった。
  2回目以降の退職所得控除は、前の退職手当等（退職手当＋それまでの給付金）と勤続期間が重なる年数を引き、下限80万円（施行令第70条第1項第2号イ・第2項）。
  前の退職手当等の合計が控除額に満たないときは、前の勤続期間を縮めて計算する。
  扶養手当は退職時の額が翌年も続くとしている。年の途中からの再就職は12か月分に直して入力してもらう。
- 入隊区分（`entryType`）：一般曹候補生（今までどおり）、任期制（任期ごとに任期満了金。満了退職か3曹昇任かを選ぶ。3曹へ昇任した場合は満了金を受けた任期を退職手当の勤続期間から除く。
  任期の途中で昇任したときの施行令第25条の特例は、一般の退職手当の額の方が大きいので一般の額で計算）、一般幹部候補生（大卒・修士・院卒。候補生の間は教育期間）。
  任期制の任用一時金・自衛官候補生の制度は令和8年10月時点の法律にないので入れていない。休職・育児休業による日数の減算（第28条第2項）は入れていない。
- 結果欄の「条件を比べる」：run() の最後に要約（latestSummary）を作り、保存したA（savedSummary）と並べる。計算には関係しない。
  「年齢ごとの内訳」は初めは閉じた details、「退職時・退職後の給付」は開いた details。印刷ではどちらも開き、比べていないときは比較の欄を出さない。
- 退職後：国民年金保険料（「退職後〜60歳の年金」で自分で納めるを選んだ場合）。「免除を受ける（退職による特例免除）」なら保険料0で、免除した月を老齢基礎年金に2分の1で数える（国民年金法第27条第8号、`afterRetire.exemptRatio`）。免除の可否（配偶者・世帯主の所得）は判定しないと健康保険料（入力した年額×年数、任意継続は2年まで）を生涯の手取りから引く。
  65歳からの公的年金は参考表示（老齢基礎年金の満額＋報酬比例。退職等年金給付・加給年金・再評価なし）で、生涯の手取りには含めない。
- 共済掛金の報酬に営内の食事（現物給与）は含めない（共済組合法施行令第5条第3項第7号：一般職の報酬に相当する給与だけ。一般職に食事の現物給与はない）。
- 特定管理職員は1佐以上で特別調整額一種・二種の人だけ（施行令第12条の5の除外の書き方から、2佐・3佐は対象外と読める）。
- 地域手当の異動保障（第11条の7第1項）：支給終了が定年より前で、6か月を超えて在勤した地域手当を「異動」とみなし、
  1年目100％・2年目80％・3年目60％の割合を保障（新しい勤務地の割合が高い月はそちら）。
  簡略化：3年以内の再異動（人事院の定め）は、重なる保障のうち高い割合を使う。異動前の割合は異動前月の年度の割合。
- 「条件から計算」（扶養・住居・通勤・単身赴任・寒冷地手当）は、入力した条件の月額が支給期間中ずっと同じとしている。
  寒冷地手当は11〜3月の5か月分を12か月にならして毎月加える。営内居住・世帯主でない乗組員は上限の半額で計算。
  通勤手当で電車と車を併用する場合は規則9-24第8条の4どおり（車2km以上は両方、2km未満は高い方。上限15万円）。駐車場の手当（第12条第5項）は入れていない。
  扶養手当の父母等の額は、将補（2）欄・1佐（1）欄で0円、1佐（2）欄で3,500円（施行令第8条の7・第8条の8、`calcRates.fuyouParentByCol`）。
- 俸給表の「昇給の見通し」は、同じ階級のまま年4号俸（将補・1佐（1）（2）欄は極めて良好の年2号俸、将は昇給なし）で、最高号俸で止める。
- 地域手当は年度ごとに割合を切り替える。
  - 令和10年4月以後：人事院規則9-49 別表第一（本則）＝ `allowances.regionalAreas`
  - 令和7年4月〜令和10年3月：人事院規則9-49-57 附則別表第一（経過措置）＝ `allowances.regionalTransition.byFy`（2025＝令和7年度、2026＝令和8年度）。表に載っていない地域はこの期間0％。
  - 令和9年度（2027）の表はまだ公布されていないので、令和8年度の表を使っている。**毎年2月ごろ**に人事院規則9-49-57の改正（新旧対照表）が出たら `byFy` に年度を足す。
  - 原文の入手先：人事院の改正通知ページの「新旧改め文（PDF）」。JILPT の法令ページ（例：2026年2月13日の 9-49-57-2）に同じ表が文字で載っていて取り出しやすいが、まれに表の一部の文字が欠けるので PDF と突き合わせる。
  - 東京都武蔵村山市は令和8年度の改正後の表に載っていない（令和7年度は7％）。原文どおり令和8年度は0％にしている。

- 特殊作戦隊員手当：施行令第12条第5項にある 26・21・16・10％ は、施行令の文言どおりの選択肢として入れた（どの隊員が当たるかを決める訓令は未確認）。

- 配置手当の上限（施行令第12条第10項：将の欄の額のうち防衛大臣が定める額と、俸給月額との差額まで）は入れていない（防衛大臣の定める額が公表資料で見つからないため）。
- 昇任時の号俸は施行令第6条の6のとおり、別表第一ロの対応表を1階級ずつ順に当てはめる（直近上位ではない）。
  例：3曹28号俸（311,300円）→2曹20→1曹16→曹長16→准尉16→3尉20号俸（325,300円）。
  防衛大臣が別に定める特例（第6条の8・第6条の10）があれば実際と違う場合がある。
- 扶養手当・住居手当・通勤手当・単身赴任手当・寒冷地手当は「条件から計算」で月額を出す（「金額を直接入力」にもできる）。条件の欄は0〜上限の整数でないとエラー（`read()`）。計算の関数（`compute`）も負の数・小数を0以上の整数に直して使う。
- 手当の行は、作ったときに選んだ手当の種類（kind）を `container.dataset.kind` と隠し欄 `.c-allowance-item__kind` に持つ（「その他（自由入力）」は `"その他"`）。賞与の基礎（`bonusBaseNames`）・階級の額（`rankRates`）・区分の額（`specialRates`）・地域手当・広域異動手当・扶養手当の父母等・期間の重なりの判定は、すべて kind で行う。手当名（`.c-allowance-item__name`）は表示とエラーの文にだけ使うので、書き換えても計算は変わらない。`read()` が返す行にも `kind` が入る（`simulator.js` は `a.kind ?? a.name` で判定）。
- 共有URLの手当の配列は `fields` の順（13番目が `.c-allowance-item__kind`）。古いURLで kind が無いときは、手当名（前後の空白を除く）が一覧の手当名と同じならその手当、違えば `"その他"` とみなす。都道府県なしの「官署指定割合」の地域手当も、割合ごと戻る。
- `branchOnly` の手当（航海手当・南極手当など）が、所属を変えたあとに残っていたら、行に「この所属では対象外です」と出し、計算はエラーで止めて削除を促す。
- 本府省業務調整手当・航海手当は「区分」を選ぶと、昇任に合わせて毎月その階級の額で計算する（`allowances.rankRates`。航海手当の5時間未満の10分の6、南極の上限額の区分、再任用自衛官の額は入れていない）。管理職員特別勤務手当（施行令第11条の2）・在宅勤務等手当（一般職給与法第12条の3、月3,000円）も区分を選ぶと額が入る。防衛出動手当（額を定める政令がない）・国際平和協力手当・特地勤務手当・第二種初任給調整手当は、法令から額を決められないので金額を入力してもらう。
- 追加した手当の支給期間は「支給開始（西暦の年・月）」と「支給期間（年・か月）」で入力する（地域手当・広域異動手当は今までどおり「入隊から何年後」）。中身は `.c-allowance-item__start`・`.c-allowance-item__end`（入隊から何年後）で持つので、共有URLの形は変わらない。入隊年・月を変えると、入隊からの時期はそのままで年月の表示が変わる。
- 途中で止まる・また始まる手当は、期間を分けて何件でも追加でき、全部が計算に入る。同じ種類（kind）の手当で支給期間が重なるとエラーで知らせ、重なった両方の行に class `is-error` と `aria-invalid` を付ける（`read()`。次の計算でエラーが消えれば外す）。地域手当・広域異動手当（異動・異動保障・再異動で重なるのが普通）と、区分（`.c-allowance-item__rate`）どうしが違う組（例：潜水と高圧室内）は除く。区分が空の行は、同じ種類のすべての行と比べる。支給開始が入隊より前・支給期間0か月もエラー（このとき期間の説明文は空にする）。
- 特殊勤務手当は、施行令 別表第五の「区分」を選ぶとその額が入る（`allowances.specialRates`）。「◯円を超えない範囲内で防衛大臣の定める額」の区分は上限額が入り、［上限額］と表示する（実際の額を決める訓令は未確認）。「ただし、一月に支給する額は◯円を超えない」区分（`specialRates` の4番目 monthMax）は、日額×日数がその額を超える月はその額にする（`amountOf`）。
- 同じ日に複数の特殊勤務手当を受けた場合の「高いほうだけ」の決まり（施行令 別表第五の備考）は入れていない。
- 教育期間（`promotion.education` の教育隊・3曹昇任前の教育・幹部候補生学校）：勤務の内容によらない生活の手当
  （扶養・住居・通勤・単身赴任・寒冷地・地域・広域異動・在宅勤務等手当。`simulator.js` の `LIVING_ALLOWANCES`）は教育期間中も支給し、賞与の基礎にも入れる。
  配置手当・特殊勤務手当などの勤務の手当、営外手当、俸給の特別調整額は教育期間中は付けない（年1回の指定場所生活調整金は対象）。
  判定は手当の行の `kind` があれば `kind`、なければ名前。簡略化：教育期間中の実際の支給の可否（教育の場所への通勤・住居の扱いなど）は個別に判定しない。
- 賞与の計算の基礎（一般職給与法第19条の4第4項・第5項、第19条の7第2項、防衛省給与法第18条の2）：
  期末手当＝俸給＋扶養手当＋営外手当＋それらに対する地域手当・広域異動手当、勤勉手当＝扶養手当とそれに対する地域手当を除いたもの。
  俸給の特別調整額に対する地域手当は賞与の基礎に入れない（月例の地域手当には入れる）。
  階級による加算は（俸給＋営外手当＋それらに対する地域手当・広域異動手当）×割合、管理職加算は俸給×割合。
- 予想階級に届かないときは、到達した階級の定年（`promotion.retireAge`）で退職として計算し直す（到達階級が下がれば繰り返す。最大5回）。
  士長などの `retireAge` にない階級は予想階級の定年のまま。入隊時の年齢が到達階級の定年以上ならエラーで知らせる。
- 自己都合で勤続42年を超える退職手当は、定年退職・勤続35年として計算する（平成15年改正法附則第4項）。調整額も定年退職と同じ扱い。若年定年退職者給付金は対象外のまま。
- 任期制→3曹：任期は在職期間（定年まで）の中だけ数える。定年までに3曹へ昇任できない入力はエラーで知らせる。

## 2026-11-22 に足した機能（どこを直すか）

- よくある経歴のひな形（`.c-preset__button`、`assets/js/simulator.js` の `PRESETS`）：入隊区分・予想階級・入隊時の年齢・昇任までの期間だけを変える。
- 年ごとの表の CSV 保存（`#csvSim`）：画面の表から端末の中で作り、どこにも送らない。= + @ で始まる値には ' を付ける。
- 3尉への昇任のしかた（`#ofcRoute`：3曹から・曹長から・准尉から）：`pathTo()` が曹の階級を順に経る道を作る。曹長からの最短2年は自衛隊法施行規則 別表第七、准尉は定めがないので1年から（`promotion.choices.stepOfcSgm / stepOfcWo`）。
- 扶養手当は子の入隊時の年齢（`c1`〜`c10`。最初は1人目だけ、「＋子を追加」で足す）から生まれた年度（`childFys`）を出し、年度ごとに 13,000円＋（生まれた年度＋16年度から）5,000円、22歳の年度末まで（一般職給与法第11条第2項・第4項）。0歳以上は「入隊年度−年齢−1」、マイナスは入隊後に生まれる子で「入隊年度＋年数」。以前の版の人数（child・teen）と生まれた年度（b1〜b4）は見えない欄で残し、共有URLで使えるようにしている。60歳以上の父母等の欄は「更新中」で入力できず、計算に入れない（階級で額が変わる決まり（施行令第8条の7・第8条の8）の扱いを見直すまで）。
- 額が自動で決まる手当（条件から計算・地域手当・広域異動手当・額の決まった区分）は、手当名と金額の欄を出さない（手当名は「その他（自由入力）」だけ）。スマホ幅（600px以下）は入力欄を1行に1つずつ並べる。
- 特地勤務手当の「条件から計算」（`calcRates.tokuchi`）：（俸給＋扶養手当）× 施行令第10条第2項の自衛官の割合。
- 転居手当（`calcRates.tenkyo`）と単身赴任手当の距離の加算の廃止（`calcRates.tanshin.addUntilFy`）：2027年4月から。

- 寒冷地手当の駐屯地・基地の一覧（`calcRates.kanreichi.bases`）：名称と位置は自衛隊法施行令 別表第七・第八・第二の二・第三、級地は寒冷地手当法 別表。駐屯地が増減・移転したり別表が改正されたら直す（`node tools/egov-check.js values` が位置と級地を照合する。北海道の振興局の管内で決まる上富良野・別海は `BY_BUREAU`）。営内者等の額は寒冷地手当支給規則第4条（`barracksRates`）。分屯基地など一覧にない官署は利用者が級地を選ぶ。
- 高等工科学校の卒業生（入隊区分 `koka`、`RULES.entry.koka`）：卒業の日の陸士長任官から計算し、在校3年間の生徒手当・期末手当は含めない。陸士長1号俸（サイトの前提。初任の号俸は防衛大臣の定めで未確認）、任官1年後に3曹（公式の案内「約1年間の教育を経た後に3等陸曹」）、任官直後の教育3か月。退職手当の勤続期間に生徒の期間の2分の1（18か月）を通算（防衛省給与法第28条の2第4項。自衛官として6か月以上）。若年定年退職者給付金の「自衛官として20年」は自衛官の期間だけ。退職所得控除の勤続年数は退職手当と同じ年数で計算（簡略化）。所属は陸上自衛隊だけ。
